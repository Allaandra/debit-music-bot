## 🌟 Ключові можливості

- 🎛️ **Повнофункціональний веб-пульт ДМа (React 19):**
  - **Керування відтворенням:** Play, Pause, швидке перемотування (Seek), випадковий порядок (Shuffle) та зациклення (Repeat треку або черги).
  - **Роздільні регулятори гучності:** Незалежні повзунки для фонової музики та звукових ефектів у реальному часі (0–200%).
  - **Миттєва синхронізація:** Синхронізація стану плеєра з усіма відкритими вкладками через **Socket.IO** (миттєве оновлення без затримок та опитування).
  - **3D-паралакс екран авторизації:** Багатошаровий кінематографічний паралакс із генератором часток Canvas, адаптивними контролами та доступною типографікою.

- ⚔️ **Звукова панель SFX (Soundboard) та ембієнт:**
  - **PCM аудіо-мікшер реального часу:** 20-мс мікшер накладає звуки ударів, заклинань та кидків кубиків поверх музики без клацань та розривів голосового потоку.
  - **Безшовні лупи ембієнту:** Спеціальний циклічний буфер (`createSeamlessLoopBuffer`) для безперервного атмосферного аудіо (дощ, багаття, таверна).
  - **Зручні категорії:** Картки категорій із векторними іконками Lucide, біжучий рядок для довгих назв (`Marquee`) та тихе передпрослуховування в навушниках майстра.
  - **Спільні звуки кампаній:** Перемикач глобального доступу (`isGlobal` 🌐) для використання звуків у різних ігрових сесіях.

- 🎵 **Мульти-джерельний стрімінг аудіо:**
  - **Інтеграція платформ:** Відтворення треків і плейлистів із YouTube, Spotify та SoundCloud.
  - **Відмовостійкий пайплайн:** Побудований на базі `yt-dlp` та `ffmpeg` з автоматичним перепідключенням, 2-годинним оновленням CloudFront-токенів (усунення 403 Forbidden) та непомітним переходом на SoundCloud fallback.
  - **Підтримка локальних файлів:** Безпосереднє відтворення аудіо з диска (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.aac`, `.opus`).
  - **3-зонний Drag & Drop:** Пакетне завантаження файлів (до 50 треків) перетягуванням із провідника напряму в плейлисти або категорії SFX.

- 🔐 **Безпека та ізоляція користувачів:**
  - **Офіційна OAuth2 авторизація:** Вхід через Discord з безпечними `httpOnly` JWT cookie-сесіями.
  - **Повна конфіденційність:** Кожен ДМ має доступ виключно до власних завантажених аудіофайлів, категорій та плейлистів.

- 🚀 **Zero-Config запуск в 1 клік:**
  - Скрипт `start_bot.bat` автоматично перевіряє оточення Node.js, встановлює бібліотеки, ініціалізує базу даних SQLite через Prisma, збирає клієнтський бандл та відкриває веб-пульт у браузері.

## 💬 Команди Discord

| Команда | Опис |
| :--- | :--- |
| `!join` | Підключає бота до вашого поточного голосового каналу та прив'язує сесію до веб-панелі |
| `!leave` | Зупиняє відтворення, очищає чергу та відключає бота від голосового каналу |
| `!np` | Відображає поточний трек, виконавця, статус та текстовий візуальний прогрес-бар |
| `!panel` | Надсилає в текстовий чат пряме клікабельне посилання на веб-пульт керування |
| `!ping` | Вимірює затримку повідомлень та пінг WebSocket з'єднання з Discord |
| `!help` | Виводить довідку з переліком усіх доступних команд бота |

## 🚀 Швидкий запуск

### Вимоги
- [Node.js](https://nodejs.org/) (рекомендовано версію 18 або новішу)
- [FFmpeg](https://ffmpeg.org/) (встановлюється автоматично через пакет `ffmpeg-static`)

### Встановлення

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/Allaandra/debit-music-bot.git
   cd debit-music-bot
   ```

2. **Налаштуйте змінні оточення:**
   Скопіюйте файл `.env.example` у `.env`:
   ```bash
   cp .env.example .env
   ```

3. **Заповніть конфігурацію в `.env`:**
   - `DISCORD_TOKEN` — токен вашого бота з [Discord Developer Portal](https://discord.com/developers/applications).
   - `DISCORD_CLIENT_ID` — Client ID додатку.
   - `DISCORD_CLIENT_SECRET` — Client Secret додатку.
   - `JWT_SECRET` — секретний ключ для підпису сесій користувачів.

4. **Запустіть бота:**
   - **Windows:** Двічі клікніть по `start_bot.bat`.
   - **Термінал:**
     ```bash
     npm install
     npm run build --prefix frontend
     npm start
     ```

Веб-пульт автоматично відкриється у вашому браузері за адресою `http://localhost:3001`.

## 🛠 Стек технологій

- **Серверна частина:** Node.js, Express 5, Socket.IO, Prisma ORM, SQLite.
- **Аудіо-ядро:** `@discordjs/voice`, FFmpeg, yt-dlp, music-metadata.
- **Клієнтський інтерфейс:** React 19, TypeScript, Vite, Lucide Icons, React Query, Context API.
- **Стилізація:** Модульний CSS, Glassmorphism, подвійна тема (Лісова темна / Ергономічна шалфейна світла).
