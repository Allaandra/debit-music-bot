# Журнал изменений и планы (Tracker & Changelog)

*Примечание: План разработки и To-Do (Roadmap) перенесены в `Agent Workspace/PLANS.md`.*

## История изменений
**[2026-09-22 - 2026-09-28]**
- Реализован стабильный стриминг через прямые ссылки YouTube (`yt-dlp` -> `ffmpeg`) с защитой от разрывов.
- Написана логика автоматического присоединения бота к голосовому каналу (шпион за `voiceStateUpdate`).
- Создан Spotify-подобный веб-интерфейс (React, CSS Grid).
- Рефакторинг бэкенда (разделение `server.ts` на отдельные роутеры).
- Добавлено извлечение обложек треков (Thumbnails) для UI.
- **Реализованы функции плеера:**
  - 🔀 **Shuffle (Перемешивание):** Очередь перемешивается с использованием честного математического алгоритма Фишера — Йетса (Fisher–Yates shuffle).
  - 🔁 **Repeat (Повтор):** Два режима работы — повтор всей очереди или зацикливание одного трека. Отражается в UI зелёным цветом и значком "1".

**[2026-10-01] - Большое архитектурное и продуктовое обновление**
- **Импорт целых плейлистов:** Добавлена поддержка вставки ссылок на плейлисты и альбомы Spotify/YouTube. Бот распознает их, показывает интерактивное модальное окно и предлагает создать новый плейлист с этими треками, либо просто добавить их в основную библиотеку.
- **Умное удаление треков:** Добавлена логика умного удаления. При попытке удалить трек, находясь внутри плейлиста, бот спрашивает: удалить только связь с плейлистом или полностью удалить песню из библиотеки (и с диска). Вне плейлистов удаление работает как и прежде.
- **Переход на Lucide React:** Статичные кастомные SVG-иконки в интерфейсе были заменены на современную библиотеку `lucide-react` для лучшей оптимизации (tree-shaking) и унификации дизайна. 
- **Очистка и стабильность (Бэкенд):**
  - Добавлены глобальные обработчики ошибок в `index.ts`, чтобы бот больше не "падал" из-за непредвиденных сетевых обрывов.
  - Удален мертвый дублирующийся код нормализации из `api/server.ts`, так как эта логика (`dynaudnorm`) уже давно встроена в `PlayerManager.ts`.
  - Исправлены зависимости в `package.json` и исправлен баг загрузчика команд при запуске скомпилированной версии бота.

**[2026-10-04 - 2026-10-05] - Документация и Нейминг**
- **Имя бота:** Официально закреплено название **Debit Music Bot (De-Bit)**. Название расшифровывается как *Decode Bitstream*, что идеально описывает главную функцию бота — мастерское декодирование аудиопотоков из сети в идеальную атмосферу для D&D партий.

**[2026-10-05] - Релиз v1.0.0 (Масштабный редизайн интерфейса)**
- **Полностью новый UI:** Внедрен современный дизайн плеера с боковыми панелями, улучшенным отображением очереди и новым музыкальным стилем (Forest Theme по умолчанию).
- **Скроллинг модулей:** Исправлены проблемы с Flexbox-контейнерами. Списки треков, очереди и плейлисты теперь корректно скроллятся.
- **Интеграция логики:** Вся логика работы с API (запуск треков, импорт, контекстные меню) успешно перенесена на новые React-компоненты.

**[2026-10-05] - Хотфиксы плеера и очереди (v0.1.5)**
- **Фикс парсинга YouTube плейлистов:** Библиотека `play-dl` сломалась из-за обновлений YouTube. Парсинг плейлистов полностью переписан на надежный `yt-dlp`.
- **Фикс заиканий (Stuttering):** Добавлены флаги самовосстановления FFmpeg (`-reconnect_on_network_error 1` и `-reconnect_on_http_error 4xx,5xx`), чтобы предотвращать вылеты с ошибкой `[tls] Error in the pull function` при микроразрывах.
- **Очередь и контекст:** Очередь (`Next up`) теперь формируется строго на основе того плейлиста, из которого запущен трек. Заголовок очереди больше не зависит от текущей открытой вкладки интерфейса.
- **Логика сортировки:** Обновлена система импорта — теперь первый трек плейлиста импортируется последним, чтобы гарантированно оказываться на самом верху списка "Недавно добавленные" в общей библиотеке.
