# Журнал изменений и планы (Tracker & Changelog)

*Примечание: План разработки и To-Do (Roadmap) перенесены в `Agent Workspace/PLANS.md`.*

## История изменений

**[2026-10-10] - Фиксы UI, Сортировка и Стабильность (v2.3.2)**
- **Фронтенд:** Устранено критическое падение приложения (зеленый экран) при логауте, вызванное ошибкой обработки ответа 401 Unauthorized. Внедрены `ErrorBoundary` и проверки в `PlayerContext`.
- **Фронтенд:** Экран авторизации вынесен в отдельный компонент `LoginScreen.tsx` для модульности и чистоты кода.
- **Фронтенд:** Инфо-панель (RightInfoPanel) больше не "моргает" при переключении треков, показывая "Resolving..." до получения реальных данных об источнике (YouTube/SoundCloud).
- **Фронтенд:** Шапки колонок в таблице треков стали кликабельными для интуитивной сортировки, добавлена зеленая подсветка активного поля сортировки. Устранены визуальные баги со шрифтом и кодировкой (знак №).
- **Бэкенд:** Восстановлено и улучшено логирование ошибок при сбоях YouTube потока в `TrackResolver` перед переключением на SoundCloud.

**[2026-10-10] - Изоляция локальных файлов и фикс путей (v2.3.1)**
- **Бэкенд:** Исправлен баг с путями при добавлении, воспроизведении и удалении локальных аудиофайлов (`../../..` вместо `../..`).
- **Бэкенд & База Данных:** Теперь каждый пользователь может загружать и видеть только свои локальные треки. Аудиофайлы сохраняются в подпапки по Discord ID (`sounds/ID/`). В модель `Track` добавлена проверка по `ownerId`.
- **Фронтенд:** Улучшена обработка ошибок в боковом меню (`LeftSidebar.tsx`) при загрузке профиля пользователя.
- **Очистка:** Удален неиспользуемый скрипт-черновик `fix_thumbnails.js`.

**[2026-10-09] - Архитектура, WebSockets и React Query (v2.3.0)**
- **Бэкенд:** Устранен "божественный объект" `PlayerManager` (400 строк), логика расщеплена на модульные сервисы: `TrackResolver`, `QueueManager` и `AudioStreamer`.
- **Сеть:** Интегрирован `Socket.io` для мгновенной передачи статуса плеера по WebSockets. Это избавило сервер от спама HTTP-запросами каждую секунду.
- **Фронтенд:** Клиент переписан с использованием `@tanstack/react-query` (кэширование и управление запросами к API) и `socket.io-client`.

**[2026-10-09] - Discord OAuth, Изоляция файлов и YouTube Fallback (v2.1.0)**
- **Бэкенд:** Реализована авторизация через Discord OAuth2. Теперь каждый Мастер Подземелий (DM) имеет собственный профиль.
- **Бэкенд:** Полная изоляция аудио-библиотеки: каждый пользователь видит и управляет только своими загруженными треками и плейлистами (привязка по Discord ID).
- **Плеер:** Внедрен надежный механизм Fallback (резервный канал) для обхода жестких блокировок YouTube (ошибка 403 / JS challenge). При неудачном запросе к YouTube бот мгновенно и незаметно переключается на поиск этого же трека в SoundCloud.
- **Фронтенд:** Интегрирован глобальный контекст пользователя, в левом боковом меню теперь отображается реальная аватарка и имя авторизованного пользователя из Discord, добавлена кнопка безопасного выхода (Logout).

**[2026-10-08] - Исправление багов с обложками и инфо-панелью**
- **Бэкенд:** Исправлен баг, из-за которого при импорте плейлистов из Spotify всем трекам прописывалась обложка плейлиста. Добавлена фоновая задача, которая асинхронно стягивает реальные обложки песен из Spotify API и обновляет их в БД.
- **Бэкенд:** Добавлен механизм самовосстановления обложек в плеере. Если во время проигрывания трека найдена обложка, которая отличается от сохранённой в БД, она автоматически перезаписывается.
- **Фронтенд:** Починена логика правой инфо-панели. Теперь она автоматически обновляет свою информацию при переключении трека (с кнопки или по окончании песни).
- **Фронтенд:** Инфо-панель теперь умеет корректно определять платформу источника (Spotify, SoundCloud, YouTube, Web) и платформу стриминга. Длинные исходные URL-адреса и специальные URI-ссылки (`spotify:track:...`) заменены на компактную кликабельную кнопку **URL**.
- **Инфраструктура:** Написан и применён скрипт миграции, который обновил обложки у всех ранее добавленных треков в базе данных пользователя.


**[2026-10-08] - Модулизация CSS и фиксы интерфейса**
- **Фронтенд:** Проведен масштабный рефакторинг стилей. Монолитный файл `App.css` (более 800 строк) полностью разобран на логические модули в папке `src/assets/css/` (например, `Globals.css`, `Themes.css`, `LeftSidebar.css` и др.).
- **Фронтенд:** Убрано дублирование инлайн-стилей в компонентах React. Теперь все компоненты используют общие CSS-классы.
- **UX/Багфикс:** Исправлен баг с выпадающими меню (Dropdowns) в левом сайдбаре. Раньше невидимый слой (click-away overlay) перекрывал меню из-за особенностей `z-index`, блокируя hover-эффекты и клики. Теперь закрытие меню по клику вне области реализовано через глобальный хук `useEffect`, а позиционирование меню исправлено.

**[2026-10-08] - Улучшения UI/UX и списка треков**
- **Фронтенд:** Если название трека (или имя автора) слишком длинное, оно больше не будет выталкивать соседние колонки. Текст просто аккуратно обрежется троеточием (...).
- **Фронтенд:** Если вы наведете мышку на трек, то обрезанный текст (и название, и автор) плавно прокрутится влево, чтобы вы могли прочитать его целиком. Скорость прокрутки рассчитывается автоматически в зависимости от длины спрятанного текста!
- **Фронтенд:** Автор трека вынесен в отдельную колонку для большей наглядности.
- **Фронтенд:** Поиск перемещен в один ряд с элементами управления плеером, а дата создания плейлиста в баннере теперь отображается реальная (и принудительно на английском языке).
- **Фронтенд:** Добавлена сортировка треков (по названию, продолжительности и автору). Настройки интерфейса (тема, свернутые панели) теперь сохраняются при перезагрузке страницы.

**[2026-10-01] - Большое архитектурное и продуктовое обновление**
- **Импорт целых плейлистов:** Добавлена поддержка вставки ссылок на плейлисты и альбомы Spotify/YouTube. Бот распознает их, показывает интерактивное модальное окно и предлагает создать новый плейлист с этими треками, либо просто добавить их в основную библиотеку.
- **Умное удаление треков:** Добавлена логика умного удаления. При попытке удалить трек, находясь внутри плейлиста, бот спрашивает: удалить только связь с плейлистом или полностью удалить песню из библиотеки (и с диска). Вне плейлистов удаление работает как и прежде.
- **Переход на Lucide React:** Статичные кастомные SVG-иконки в интерфейсе были заменены на современную библиотеку `lucide-react` для лучшей оптимизации (tree-shaking) и унификации дизайна. 
- **Очистка и стабильность (Бэкенд):**
  - Добавлены глобальные обработчики ошибок в `index.ts`, чтобы бот больше не "падал" из-за непредвиденных сетевых обрывов.
  - Удален мертвый дублирующийся код нормализации из `api/server.ts`, так как эта логика (`dynaudnorm`) уже давно встроена в `PlayerManager.ts`.
  - Исправлены зависимости в `package.json` и исправлен баг загрузчика команд при запуске скомпилированной версии бота.

**[2026-10-05] - Релиз v1.0.0 (Масштабный редизайн интерфейса)**
- **Полностью новый UI:** Внедрен современный дизайн плеера с боковыми панелями, улучшенным отображением очереди и новым музыкальным стилем (Forest Theme по умолчанию).
- **Скроллинг модулей:** Исправлены проблемы с Flexbox-контейнерами. Списки треков, очереди и плейлисты теперь корректно скроллятся.
- **Интеграция логики:** Вся логика работы с API (запуск треков, импорт, контекстные меню) успешно перенесена на новые React-компоненты.

**[2026-10-05] - Хотфиксы плеера и очереди (v0.1.5)**
- **Фикс парсинга YouTube плейлистов:** Библиотека `play-dl` сломалась из-за обновлений YouTube. Парсинг плейлистов полностью переписан на надежный `yt-dlp`.
- **Фикс заиканий (Stuttering):** Добавлены флаги самовосстановления FFmpeg (`-reconnect_on_network_error 1` и `-reconnect_on_http_error 4xx,5xx`), чтобы предотвращать вылеты с ошибкой `[tls] Error in the pull function` при микроразрывах.
- **Очередь и контекст:** Очередь (`Next up`) теперь формируется строго на основе того плейлиста, из которого запущен трек. Заголовок очереди больше не зависит от текущей открытой вкладки интерфейса.
- **Логика сортировки:** Обновлена система импорта — теперь первый трек плейлиста импортируется последним, чтобы гарантированно оказываться на самом верху списка "Недавно добавленные" в общей библиотеке.

**[2026-10-09] - Prisma Migration & YouTube Bypass (v2.2.0)**
- **Feature:** Полностью перевели базу данных на Prisma ORM (файлы схем в prisma/).
- **Fix:** Решена проблема фантомных сессий при дисконнекте. Теперь команды /join и /leave четко управляют подключением к каналам и сессиями в БД.
- **Fix:** Значительно ускорена выдача треков из yt-dlp за счет флагов оптимизации (--no-playlist, --skip-download и др.).
- **Fix:** Обход блокировок YouTube 429: реализована передача куки из файла и молниеносный fallback на SoundCloud для любых текстовых запросов и ссылок YouTube (через oEmbed API).
- **Feature:** Добавлен скрипт start_bot.bat для запуска сервера и автоматического открытия веб-пульта (Zero-config deployment).
