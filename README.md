# Debit Music Bot 🎧🐉

**Debit Music Bot (De-Bit)** — специализированный Discord-бот с интерактивным веб-интерфейсом в стиле Spotify для проведения D&D и других настольных ролевых игр (TTRPG). Бот позволяет Мастеру Подземелий (DM) легко управлять атмосферным звуковым сопровождением: плавно переключать боевую музыку, эмбиент таверн и в реальном времени накладывать звуковые эффекты (SFX) поверх играющих треков.

---

## 🌟 Ключевые возможности

- 🎛️ **Полноценный веб-пульт ДМа (React 19):**
  - Управление воспроизведением: Play, Pause, Seek (перемотка), Shuffle (случайный порядок), Repeat (повтор трека/очереди).
  - Раздельные независимые регуляторы громкости фоновой музыки и звуковых эффектов.
  - Мгновенная синхронизация состояния плеера со всеми открытыми вкладками через **Socket.IO** (без задержек и полинга).
- ⚔️ **Звуковая панель SFX (Soundboard):**
  - Встроенный аудио-микшер реального времени: воспроизведение звуков ударов, выстрелов, магии и кубиков прямо поверх музыки без прерывания и щелчков.
  - Двухэтапная нормализация громкости (EBU R128 `loudnorm` и `dynaudnorm`) для идеального баланса звуков.
  - Категории эффектов с векторными иконками, бегущей строкой для длинных названий (`Marquee`) и тихим предпрослушиванием в наушниках ДМа.
  - Возможность делиться своими звуковыми эффектами с другими мастерами (флаг `isGlobal` 🌐).
- 🎵 **Аудио-источники и стриминг:**
  - Поддержка ссылок YouTube, плейлистов и альбомов Spotify, треков SoundCloud.
  - Надежный аудио-пайплайн на базе `yt-dlp` и `ffmpeg` с защитой от разрывов (`reconnect`) и автоматическим fallback на SoundCloud при блокировках YouTube.
  - Воспроизведение локальных файлов с диска (`.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`, `.aac`, `.opus`).
- 🔐 **Безопасность и многопользовательский режим:**
  - Авторизация через официальный Discord OAuth2 с безопасными `httpOnly` JWT-сессиями.
  - Полная изоляция библиотек и плейлистов: каждый ДМ видит и управляет только своими загруженными файлами.
- 🚀 **Zero-Config запуск в 1 клик:**
  - Скрипт `start_bot.bat` автоматически проверяет окружение, устанавливает зависимости, инициализирует базу данных SQLite через Prisma, собирает фронтенд и открывает веб-пульт в браузере.

## 💬 Команды Discord

| Команда | Описание |
| :--- | :--- |
| `!join` | Подключает бота в ваш голосовой канал и привязывает сессию к веб-панели |
| `!leave` | Останавливает воспроизведение, очищает очередь и отключает бота от канала |
| `!np` | Показывает текущий играющий трек, автора, статус и текстовый прогресс-бар |
| `!panel` | Отправляет в чат кликабельную ссылку на веб-пульт управления |
| `!ping` | Проверяет сетевую задержку сообщений и пинг Discord WebSocket |
| `!help` | Выводит справку со списком всех доступных команд |

## 🚀 Быстрый запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Allaandra/debit-music-bot.git
   cd debit-music-bot
   ```
2. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Заполните необходимые переменные в `.env`:
   - `DISCORD_TOKEN` — токен вашего Discord-бота.
   - `DISCORD_CLIENT_ID` — Client ID приложения в портале разработчиков Discord.
   - `DISCORD_CLIENT_SECRET` — Client Secret приложения Discord.
   - `JWT_SECRET` — секретный ключ для подписи сессий веб-панели.
4. Запустите бота двойным кликом по `start_bot.bat` (или выполните `npm run start` в терминале).

## 🛠 Стек технологий

- **Сервер:** Node.js, Express 5, Socket.IO, Prisma ORM, SQLite.
- **Аудио-движок:** `@discordjs/voice`, FFmpeg, yt-dlp, music-metadata.
- **Фронтенд:** React 19, TypeScript, Vite, Lucide Icons, Context API.
