# Debit Music Bot 🎧🐉

**Debit Music Bot (De-Bit)** — это продвинутый музыкальный Discord-бот, созданный специально для Dungeon Masters (Мастеров D&D и других НРИ). Он позволяет удобно управлять музыкальным сопровождением и аудио-эмбиентом во время игры через полноценный веб-интерфейс в стиле Spotify.

Название **De-Bit** расшифровывается как *Decode Bitstream*, ведь бот мастерски декодирует аудиопотоки, превращая их в идеальную атмосферу для ваших приключений!

## Главные фичи 🌟
- **Веб-интерфейс:** Удобная панель управления (React) для контроля музыки (Play, Pause, ползунки громкости и времени, управление очередью).
- **YouTube и локальные файлы:** Стриминг аудио с YouTube (без лагов, через `yt-dlp` и `ffmpeg`) и загрузка собственных `.mp3`/`.wav` файлов.
- **Плейлисты и база данных:** Автоматическое сохранение добавленных треков (SQLite), поддержка плейлистов для разных сцен (таверна, боевка, лес).
- **Умный плеер:** Поддержка режимов Shuffle (перемешивание) и Repeat (повтор трека или очереди), извлечение обложек треков.
- **Zero-Config Запуск:** Установка и запуск в один клик через `start_bot.bat` (скрипт сам всё соберет и запустит).

## Установка и запуск 🚀

1. Склонируйте репозиторий.
2. Скопируйте файл `.env.example`, переименуйте его в `.env` и укажите ваш `DISCORD_TOKEN`.
3. Убедитесь, что у вас установлен **Node.js**, а также **FFmpeg** (должен быть прописан в системных переменных PATH).
4. Запустите `start_bot.bat` — скрипт установит все NPM-зависимости, скомпилирует фронтенд и запустит бота.

## Стек технологий 🛠
- **Backend:** Node.js, Express.js, Discord.js (`@discordjs/voice`), SQLite.
- **Frontend:** React 19, Vite.
- **Аудио-движок:** yt-dlp, FFmpeg, play-dl.
